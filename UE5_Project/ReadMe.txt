初めからチームで制作しました。
テーマ：対戦ゲーム
制作期間：2025/06/23 ~ 2025/07/30 (α版　－　100時間)　+ 2025/09/24 ~ 2025/10/27（β版　－　50時間）　｜150時間程度
エンジン：Unreal Engine 5
言語：C++ / BluePrint

________________________________________________________________
コンセプト：釣った魚で最後の一人になるまで戦おう！
闘技場になった無人島で戦って生き残るアクションゲームです。ところで、釣竿しかないので、釣った魚で戦うしかありません。
魚によって、効果などが違うので、最初に釣った魚で行くか、リスクを取ってもっと良さそうな魚を釣るか。
________________________________________________________________
目的：UnrealEngine5での経験を得て、マルチプレイヤーのゲームを作成すろこと。そのためにReplicationやサーバー/クライアントの関係、ゲームのネットワークについて学習して実装しました。
さらに、メインメニューとマッチメイキングの実装方法を学んで作りました。

操作方法
・メニューの操作方法：
 →「始める」
 	【サーバーを立ちたいか、一人で遊びたい時】
 	→　名前を入力してから「ゲームホスト」(部屋を作る画面に移動する)　
 	→　部屋のパラメータを入力/設定してから「作る」（マッチメイキング画面に移動する）
 	→　マッチメイキングで他のプレヤーを待つか好きなタイミングで「準備」ボタンを押してから「始める」（全員が準備済みのみ）
 	→　ゲームスタート！

 	【クライアントとしてゲームに参加する時のみ（一人プレイ不可）】
 	→　名前を入力してから「ゲームに参加」(部屋を見つける画面に移動する)　
 	→　参加したい部屋のところに「参加」ボタンを押す（マッチメイキング画面に移動する）
 	→ 「準備」ボタンを押して、ゲームスタートを待つ（サーバーのホストしか開始出来ない）


　・WASDで移動
　・マウス操作で視点移動
　・2 3 4キーで武器装備
　・釣り竿装備状態でFキーで釣り(釣り場にいるときのみ)
　・shiftキーで回避
　・武器装備状態でマウス左クリックで攻撃
　・spaceキーでジャンプ
　・Gキーで魚を食べて回復
